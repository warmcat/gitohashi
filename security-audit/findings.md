# gitohashi Continuous Security Audit — Findings Index

One row per finding, global ids `F-NNN` assigned in order of filing, never
reused.  Each finding's canonical, self-contained artifact is
`findings/F-NNN.md` (front matter is machine-parseable); this index is the
browse layer, and the originating report in `reports/` is the immutable
pass history.  Severity/confidence definitions in `METHODOLOGY.md`.

Status: `open` | `fixed` (with commit) | `disputed` | `wontfix` (with
reason).  Re-observations of an open finding update `findings/F-NNN.md`,
they do not create a new id.
