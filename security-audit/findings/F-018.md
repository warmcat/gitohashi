# F-018 — uninitialized `c` in the log end-block

## Location

- `lib/job/log.c:83` — `git_commit *c;` (uninitialized)
- `:89` — `git_commit_parent(&c, ctx->u.commit, 0);` — on
  GIT_ENOTFOUND (root commit has no parent) libgit2 leaves `*out`
  untouched
- `:90-93` — `if (c) { … jg2_json_oid(git_commit_id(c), ctx); }`

## Build gating

None — default build; any log or summary view.

## Attack path

1. The repo's first-parent chain length is exactly **count+1** (51 for
   log views, 11 for summary's chained log) — attacker-influenced repo
   shape; the count exhausts while `u.commit` is the root commit.
2. End-block: `git_commit_parent(&c, root, 0)` returns GIT_ENOTFOUND
   without writing `c`.
3. `c` holds stale stack contents — in practice the previous loop
   iteration's **freed** commit pointer (same stack slot, freed at
   :120).
4. `if (c)` takes the branch → `git_commit_id(c)` reads freed/garbage
   memory → a garbage "next" oid is emitted into the JSON (broken next
   link) or the worker crashes on an unmapped pointer.  The libgit2
   object cache usually still holds the freed commit, masking it.

## Evidence

The asymmetry inside the same file: the loop body at :118 does
`c = NULL;` before the identical call, and reflist.c:75-85 documents the
same class for `rref` — the end-block predates the discipline.

## Impact

Uninitialized-pointer deref (read-only) with deterministic per-repo-shape
timing, unauthenticated trigger; typical outcome a corrupt "next" oid,
worst case a worker crash.  Low, high confidence (mechanism verified
against libgit2's ENOTFOUND contract — `*out` untouched).

## Remediation sketch

`git_commit *c = NULL;` at declaration, and emit "next" only when
`git_commit_parent()` returns 0.

## Status history

- 2026-09-13 — filed open by SA-007 (job-lists pass).

- 2026-09-18 — **fixed** in `90bd8f9`: c = NULL plus the "next" emission gated on the parent lookup succeeding.  Verified against a purpose-built 51-commit repo (chain == count+1, the exact hazard shape): 50 entries, no bogus next, clean termination.
