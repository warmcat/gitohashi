# F-021 — escaper quote gap + raw-URL interpolation in jg2.js

## Location

- Escapers: `assets/jg2.js:393-414` — `san`/`san_nq` replace
  `& < > " %` but **not `'`**
- Single-quoted attribute sinks with repo content:
  `:1342-1345`, `:1351-1354` (tree entry `href='…'` — filenames),
  `:919` (identity `alt='…'` — emails),
  `:964-965`, `:976-977`, `:1108-1109` (aliases/patch_archive
  `tgt='…'` — branch/tag names)
- Raw-URL sinks: `:2125-2150` (breadcrumb `e[n]` as unescaped link
  text + `makeurl(..., rpath, ...)` into double-quoted hrefs);
  `:2442-2525` (`rpath`/`qbranch`/`qid` are raw `window.location`
  slices, never escaped)

## Build gating

None — default asset set.  Strict CSP (`script-src 'self'`, no
unsafe-inline) fences both legs to passive markup/attribute injection —
injected event handlers and inline styles do not execute.

## Attack path

**Leg (a) — repo pusher**: git tree entry names, branch/tag names
(refname rules allow `'`) and commit emails containing `'` close the
single-quoted attribute early → injected attributes/markup in tree
listings, identity tooltips, and log/commit ref decorations for every
viewer.

**Leg (b) — unauthenticated**: `rpath` is a client-side raw slice of the
location; `GET /git/<real-repo>/tree/a"><img src=x onerror=…>` reaches
the breadcrumb href/text unescaped (the repobar renders before the
error item; JSON arrives for any resolvable repo) → markup injection in
the rendered page.  `qbranch`/`qid` slices reach hrefs the same way.

## Evidence

`san()`'s replacement list vs the single-quoted attributes at the
sinks; `e[n]` and the `makeurl` args at :2125-2150 bypass `san`
entirely; `makeurl` itself never escapes.

## Impact

CSP-gated DOM injection — no script execution; content/link spoofing and
href reshaping (click-phishing inside the origin).  Same grading as
F-008 (whose server-side fix purified the same class of input); Low,
medium confidence (gaps code-verified; browser testing out of audit
scope).

## Remediation sketch

Add `'`→`&#39;` to `san`/`san_nq`; route the breadcrumb components and
all `makeurl` string args through `san` (or make `makeurl` escape its
arguments itself); prefer double-quoted attributes for URL-shaped
values.
